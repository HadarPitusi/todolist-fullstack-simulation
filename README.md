# 📝 ToDoList – Full-Stack Client-Server Simulation Project

This project was developed as part of a Full-Stack Web Development course. It simulates a task management system (ToDo List) using SPA architecture, featuring client-side logic, simulated servers, communication, and local data storage.

---

## 🔧 Technologies & Tools

- **HTML, CSS, JavaScript (OOP)**
- **SPA (Single Page Application) Architecture**
- **FAJAX** – Simulated AJAX mechanism
- **JSON** for data representation and exchange
- **LocalStorage** as a mock database
- **Git** for version control

---

## 🧠 Key Features

- User registration and login screens (with validation)
- Full task management: add, edit, delete, and search
- Asynchronous server response simulation with unstable communication (delays, dropped requests)
- Two separate simulated servers – one for users and one for tasks
